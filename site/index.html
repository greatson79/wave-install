01 · 준비물

시작하기 전에 4가지만 확인하세요.

  • 유료 Claude 계정설치 중 로그인합니다. 무료 계정으로는 사용할 수 없습니다.
  • Mac 또는 Windows 컴퓨터Mac은 터미널, Windows는 PowerShell 창을 씁니다. 아래에서 열기 방법을 알려 드립니다.
  • 인터넷 연결설치 중 필요한 파일을 내려받습니다.
  • 저장 공간 약 5GB빈 공간이 부족하면 설치가 처음에 멈추고 이유를 알려 줍니다.

02 · 설치

내 컴퓨터를 고르고, 한 줄을 붙여넣으세요.

Mac · 터미널에 붙여넣기
curl -fsSL https://github.com/greatson79/wave-install/releases/download/v0.2.4/bootstrap.sh -o "$HOME/install-wave.sh" && bash "$HOME/install-wave.sh"

복사한 뒤 아래 순서대로 하세요.

  1. 01 설치 파일 받기·확인
  2. 02 Claude Code 설치·업데이트
  3. 03 Wave Terminal 설치
  1. 터미널을 엽니다. Command+Space를 누르고 터미널을 입력한 뒤 Return.
  2. 위의 한 줄을 붙여넣습니다. Command+V.
  3. Return을 누릅니다. 이후 화면에 뜨는 안내를 아래 표와 맞춰 보며 진행하세요.
  1. PowerShell을 엽니다. 시작 메뉴를 열고 PowerShell을 입력한 뒤 Windows PowerShell을 선택합니다. 관리자 권한으로 열 필요는 없습니다.
  2. 위의 한 줄을 붙여넣습니다. 창 안에서 마우스 오른쪽 버튼을 누르면 붙여넣어집니다.
  3. Enter를 누릅니다. 이후 화면에 뜨는 안내를 아래 표와 맞춰 보며 진행하세요.

04 · 설치 후 첫 실행

처음 열 때 한 번, 경고가 뜹니다.

Wave Terminal은 아직 Apple·Microsoft의 정식 인증을 받지 않은 앱입니다. 그래서 처음 열 때 운영체제가 경고를 보여 줍니다. 앱이 변조되지 않았는지는 설치 프로그램이 파일 지문(SHA256)으로 이미 확인했습니다.

Mac처음 열기
  1. Finder에서 설치된 Wave Terminal 앱을 찾습니다. 설치 마지막 화면이 위치를 알려 줍니다.
  2. 앱을 Control을 누른 채 클릭(또는 오른쪽 클릭)하고 열기를 고릅니다.
  3. 경고 창에서 다시 열기를 누릅니다.
  4. 창(좌석) 2개가 보이면 설치가 끝난 것입니다.

계속 열리지 않으면 더 시도하지 말고 화면 사진과 함께 문의해 주세요.

Windows처음 열기
  1. 시작 메뉴를 열고 Wave Terminal을 입력해 앱을 선택합니다.
  2. 파란 SmartScreen 창이 뜨면 추가 정보 → 실행을 누릅니다.
  3. 창(좌석) 2개가 보이면 설치가 끝난 것입니다.

시작 메뉴에 앱이 보이지 않으면 문의해 주세요.

05 · 막혔을 때

혼자 고민하지 말고 보내 주세요.

브라우저에서 유료 Claude 계정 로그인을 끝낸 뒤 설치 창으로 돌아와 안내대로 이어 가세요. 로그인 코드는 다른 사람에게 보내지 마세요.

그 파일은 실행하지 말고 삭제하세요. 한 줄을 처음부터 다시 실행해도 같으면 설치를 멈추고 문의해 주세요.

설치팩 zip을 직접 받은 경우

wave-install-0.2.4.zip을 내려받아 압축을 풀면 wave-install-0.2.4 폴더가 생깁니다. 터미널에서 cd ~/Downloads/wave-install-0.2.4 && bash bootstrap.sh 한 줄만 실행하세요(위의 설치 명령은 칠 필요 없음).

설치기가 확인하는 것

공식 저장소 greatson79/wave-terminal의 Release에서 받은 파일인지, 설치기에 고정된 SHA256 지문과 일치하는지를 확인합니다. macOS는 앱 codesign 검증을 추가로 합니다. 이 검증은 파일이 변조되지 않았다는 확인이며 Apple 공증을 대신하지 않습니다. 현재 macOS 공증은 받지 않았고(spctl 거부), Windows는 Authenticode 코드서명이 없습니다. 전체 설치 실측은 진행 중입니다.

Mac에서 격리 속성을 직접 풀어야 할 때

출처와 지문을 확인했고, 위의 열기 방법으로도 열리지 않을 때만 사용하세요. 설치된 Wave Terminal 앱에 한해 xattr -dr com.apple.quarantine "$HOME/.wave/apps/Wave Terminal.app"을 실행합니다. 다른 위치에 복사했다면 실제 앱 경로로 바꾸세요. 서명 문제를 고치지는 않습니다.

    오류 ID별 안내

    OS_UNSUPPORTED 운영체제 또는 셸이 지원 대상이 아닌가요?

    macOS·Windows의 최신 지원 범위와 셸 조건을 확인한 뒤, 조건이 맞지 않으면 문의해 주세요.

    CHECKSUM_MISMATCH SHA256이 일치하지 않나요?

    파일을 실행하거나 재사용하지 말고 삭제한 뒤, 공식 Release에서 다시 받아 비교하세요. 계속 다르면 다운로드를 중단합니다.

    CLAUDE_LOGIN_REQUIRED Claude 로그인이 멈췄나요?

    브라우저에서 유료 Claude 계정 로그인을 완료한 뒤 설치기의 해당 단계로 돌아옵니다. 인증 코드는 공개 채널에 남기지 마세요.

    DAEMON_START_FAILED 데몬 등록에 실패했나요?

    기본값은 켜짐이지만 선택 단계입니다. 로그 한 파일을 보존하고, 재설치 전에 오류 ID와 운영체제를 기록하세요.

    재설치 / 초기화

    상태 파일과 로그를 확인한 뒤 필요한 작업만 선택하세요. 초기화 전에는 보존할 로그를 먼저 복사합니다. reinstall.sh는 설치 파일을 다시 적용하고, reset.sh --list는 삭제 대상을 미리 보여 줍니다.
