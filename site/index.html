    03 / FIRST RUN

    macOS 공증 미완: 실행 전에 현재 상태를 확인하세요.

    두 DMG 모두 Apple 공증 없음 · spctl 거부됨. arm64 앱은 리소스 봉인 검증에 실패했고, x64 앱은 미서명입니다. SHA256·minisign 검증은 배포 파일의 무결성 확인이며 Apple 공증을 대신하지 않습니다.

    macOSGatekeeper
    1. 공식 Release에서 받은 DMG의 SHA256SUMS·minisign 검증부터 확인합니다.
    2. DMG에서 사용자 폴더로 복사한 앱의 위치를 확인합니다.
    3. 앱을 Control-클릭(또는 우클릭)하고 열기를 선택합니다.
    4. 출처와 무결성을 확인하고 격리속성 해제를 직접 선택한 경우에만, 설치된 해당 앱에 한해 xattr -dr com.apple.quarantine "$HOME/.wave/apps/Wave Terminal.app"을 실행합니다. 다른 위치에 복사했다면 실제 앱 경로로 바꾸세요.
    5. 격리속성 해제는 서명 결함을 고치거나 공증을 추가하지 않습니다. 실행 성공은 확인되지 않았으며, 계속 차단되면 중단하고 오류를 전달하세요.

    해시가 다르거나 출처를 확인할 수 없으면 실행하지 마세요.

    Windows준비 중

    Windows 설치기는 준비 중입니다.

    1. 현재 공개 릴리스에는 Windows 설치 자산이 없습니다.
    2. Windows 설치기와 검증 절차가 준비되면 이 페이지와 릴리스 자산을 함께 갱신합니다.
    3. 현재는 지원되는 macOS 설치 절차를 이용해 주세요.

    Windows 설치 자산이 준비되기 전에는 설치를 진행하지 마세요.

    05 / HELP

    막힌 단계에서 다시 시작하세요.

    오류 ID는 설치기의 troubleshooting/ 키와 맞춥니다.

    OS_UNSUPPORTED 운영체제 또는 셸이 지원 대상이 아닌가요?

    macOS·Windows의 최신 지원 범위와 셸 조건을 확인한 뒤, 조건이 맞지 않으면 문의해 주세요.

    CHECKSUM_MISMATCH SHA256이 일치하지 않나요?

    파일을 실행하거나 재사용하지 말고 삭제한 뒤, 공식 Release에서 다시 받아 비교하세요. 계속 다르면 다운로드를 중단합니다.

    MINISIGN_INVALID minisign 검증이 실패했나요?

    공개키·서명 파일·릴리스 태그가 같은 버전인지 확인하세요. 확인할 수 없다면 실행하지 말고 지원 주소로 알려 주세요.

    CLAUDE_LOGIN_REQUIRED Claude 로그인이 멈췄나요?

    브라우저에서 유료 Claude 계정 로그인을 완료한 뒤 설치기의 해당 단계로 돌아옵니다. 인증 코드는 공개 채널에 남기지 마세요.

    DAEMON_START_FAILED 데몬 등록에 실패했나요?

    기본값은 켜짐이지만 선택 단계입니다. 로그 한 파일을 보존하고, 재설치 전에 오류 ID와 운영체제를 기록하세요.

    RECOVERY

    재설치 / 초기화
